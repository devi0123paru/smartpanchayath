# SmartPanchayath

SmartPanchayath is a Streamlit-based application designed to support panchayat-level property mapping and construction change monitoring.

## Features

- Construction change detection
- GPS-based property mapping
- Property and map visualization
- Historical imagery analysis, if configured
- Risk assessment and anomaly detection, if implemented

## Technology Stack

- Python
- Streamlit
- Geographic and image-processing libraries used by the project

## Run Locally

1. Clone or download this repository.
2. Create and activate a Python virtual environment.
3. Install the project's dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Start the Streamlit application:

   ```bash
   streamlit run app.py
   ```

## Notes

Features and setup requirements depend on the current project implementation and configuration. Do not commit API keys, passwords, or sensitive citizen/property data.
